# Source Policy

Owner of source handling for [SKILL.md](../SKILL.md). Load when you write any visible word or source.

- If the user supplies complete material and asks only to render it, transform only that material.
- Verify current facts, product/company/person/version details, financial claims, release dates, and latest/recent claims against primary sources before rendering.
- Render a visible Sources section when browsing or research is used.
- Render a visible Credits section when third-party copied or adapted material requires attribution.
- If sources conflict or cannot be checked quickly, spend the one question of [contract § Question budget](contract.md#question-budget) on it, or mark the claim `[DATA NEEDED: …]`.
- Metadata comments may include template name, vpk-html version, render timestamp, and source labels or basenames. They must not include absolute source file paths by default.
